# Layer-2 Engineering Layer

Executable control layer for CASEPATH/KEX.

The ToT safety kernel is the admission boundary. The coordinate directory is a distinct address-resolution component. The Layer-2 reconciler is downstream and does not silently overwrite same-order divergent state.

The implementation is transport-neutral and currently process-local. It therefore does not claim that a networked distributed system has already been constructed.

Run:

    node runtime/layer2/kex_l2_engine.js

Exit status is zero only when the built-in falsification suite passes.
